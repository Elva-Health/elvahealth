# ELVA Health

Production-ready static website for ELVA — medication management made simpler.

## Stack

- React + Vite
- Tailwind CSS
- React Router
- lucide-react

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Routes

- `/` — Home
- `/how-it-works` — How It Works
- `/why-elva` — Why ELVA
- `/faq` — FAQ
- `/contact` — Contact
- `/privacy` — Privacy Policy
- `/terms` — Terms & Conditions
